# 실험: Jamo vs G2PK2 음성 합성 퀄리티 비교

## 개요

한국어 TTS에서 G2P(Grapheme-to-Phoneme) 방식이 학습 속도 및 최종 합성 품질에 미치는 영향을 비교한다.

- **조건 A (Jamo)**: 자모를 직접 phoneme으로 사용 (기존 방식)
- **조건 B (G2PK2)**: G2PK2 라이브러리로 음운 규칙을 적용한 phoneme 사용

---

## 연구 질문

1. **학습 속도**: 동일한 학습 step에서 G2PK2 적용 모델이 더 자연스러운 발음을 내는가?
2. **최종 품질**: 충분히 학습된 후 G2PK2 모델의 발음 정확도가 더 높은가?

---

## Val 리스트 선정 기준

### 선정 방법

`find_val_candidates.py`를 이용해 esd.list 전체 문장에서 jamo ↔ g2pk2 phoneme 편집 거리가 가장 큰 문장을 추출한다.

```bash
uv run python find_val_candidates.py --top 50 --out candidates.tsv
```

### 포함 기준

- **7종성법** 적용 문장 (받침 중화: ㅈ→ㄷ, ㅊ→ㄷ, ㅌ→ㄷ, ㅍ→ㅂ, ㄲ→ㄱ 등)
  - 예: 낮, 꽃, 밭, 잎, 밖 등이 포함된 문장
- **연음** 적용 문장 (받침+모음 연결: `국어` → `구거`)
- **비음화** 적용 문장 (`국민` → `궁민`, `입니다` → `임니다`)
- **경음화** 적용 문장 (`백과` → `백꽈`)
- G2PK2로 인해 phoneme 시퀀스가 실질적으로 바뀌는 문장 (단순 표기 차이 제외)

### 포함 제외 기준

- G2PK2 적용 전후 phoneme 차이가 없는 문장
- 매우 짧은 문장 (5음절 미만)
- 외래어·숫자가 대부분인 문장

### ⚠️ 알려진 문제: normalize_text의 숫자 변환 신뢰성

`normalize_text()`는 `num2words`로 아라비아 숫자를 한글로 변환한다 (예: `20년` → `이십년`). 그러나 한국어에서 숫자 읽기는 문맥에 따라 다르며 (`20년` → `스무 년` vs `이십 년`), KSS 데이터셋의 음성 자체가 특정 발음으로 녹음되어 있으므로 자동 변환 결과가 실제 발화와 다를 수 있다.

- **현재 방침**: 일단 방치. 실험의 주요 관심사(jamo vs g2pk2)와 직접적 관련 없음
- **장기적으로**: 데이터셋 자체의 발음 표기를 신뢰하는 방향으로 normalizer 재검토 필요

### ⚠️ 알려진 문제: 숫자·알파벳 토큰 누락

숫자, 알파벳 등 비한글 문자가 포함된 문장에서 해당 토큰이 jamo·G2PK2 양쪽 G2P 모두에서 무시(누락)되는 현상이 확인되었다. 이 경우 실제 발화 오디오와 phoneme 시퀀스 사이에 불일치가 발생하므로, 해당 문장을 학습 데이터에서 제외해야 할 수 있다.

- **증상**: `normalize_text()` 이후 숫자·영문이 한글로 변환되지 않고 그대로 남을 경우, `_decompose()`에서 처리되지 않고 건너뜀
- **영향 범위**: val 리스트뿐 아니라 train 데이터 전체에 해당 가능성 있음
- **대응 방안 (미결)**: 전처리 단계에서 해당 문장을 필터링하거나, 숫자·알파벳을 한글 발음으로 변환하는 전처리 추가 필요

### 목표 구성 (총 15~20문장)

| 범주 | 문장 수 |
|------|---------|
| 7종성법 중심 | ~5문장 |
| 연음 중심 | ~4문장 |
| 비음화 중심 | ~4문장 |
| 경음화·기타 | ~3문장 |
| 혼합 (여러 규칙 동시) | ~4문장 |

> 실제 문장은 candidates.tsv를 검토한 후 사용자가 최종 선정한다.

## 평가 방법

### 청취 주관 평가 (ABX 방식)

1. 동일 문장에 대해 두 모델(A: Jamo, B: G2PK2)의 합성 결과를 쌍으로 비교
2. 평가 기준:
   - **발음 자연스러움**: 어느 쪽이 더 한국어답게 들리는가
   - **음운 규칙 적용**: 받침 처리, 연음 등이 올바르게 발음되는가
3. 비교 step: 10k, 30k, 60k, 100k, 160k (epoch 완료 시점)

### 보조 지표

- TensorBoard mel loss, kl loss 추이 비교 (두 모델 동일 step 기준)
- (선택) Whisper ASR로 생성 음성 전사 후 CER 측정
